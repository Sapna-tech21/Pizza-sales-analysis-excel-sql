# Pizza Sales Analysis Dashboard | Excel Project
## Project Overview
This project focuses on analyzing pizza sales data using Microsoft Excel.
The goal of the project is to perform data cleaning, data processing, and build an interactive dashboard to uncover meaningful business insights from the sales data.

The analysis helps understand customer purchasing behavior, sales performance, best-selling pizzas, peak order timings, and category-wise contribution to revenue.

## Objectives
Clean and process raw pizza sales data

Create KPI metrics for business analysis

Analyze sales trends and customer ordering patterns

Build an interactive Excel dashboard

Generate actionable business insights

## Tools & Technologies Used
Microsoft Excel

Pivot Tables

Pivot Charts

## Dashboard Design

Project Workflow

Data Cleaning

Performed the following data cleaning steps:

Removed duplicate records

Handled missing/null values

Standardized date and time format

Corrected inconsistent category names

Verified quantity and price columns

Converted raw data into structured tabular format

## Data Processing

Created calculated fields and metrics such as:

Total Revenue

Average Order Value

Total Orders

Total Pizzas Sold

Average Pizzas Per Order

Used Pivot Tables and formulas to summarize and analyze the data.

# KPI Metrics
Key Performance Indicators (KPIs)
1. Total Revenue

Total income generated from pizza sales.

2. Average Order Value

Average amount spent per order.

3. Total Pizzas Sold

Total quantity of pizzas sold.

4. Total Orders

Total number of orders placed.

5. Average Pizzas Per Order

Average number of pizzas purchased in each order.

# Business Analysis Questions

The dashboard answers the following business questions:

Daily Trend for Total Orders

Hourly Trend for Orders

Percentage of Sales by Pizza Category

Percentage of Sales by Pizza Size

Total Pizzas Sold by Pizza Category

Top 5 Best Sellers by Total Pizzas Sold

Bottom 5 Best Sellers by Total Pizzas Sold

# Dashboard Features
Interactive filters using slicers

Dynamic charts and graphs

KPI cards for quick insights

Category-wise sales analysis

Hourly and daily sales trends

Best and worst performing pizzas visualization

# Key Insights

Some useful insights identified from the analysis:

Peak sales occur during evening hours and weekends.

Large-size pizzas contribute the highest revenue.

Classic and Supreme categories generate maximum sales.

A few pizza varieties consistently drive the majority of orders.

Bottom-performing pizzas may require promotional strategies or menu optimization.
